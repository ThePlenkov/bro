# RFC-1 — Markdown templates

## Summary

Every durable project document is a templated md file.

## Motivation

Ad-hoc doc shapes drift; a pinned template keeps them honest.

## Design

A template is an example doc: frontmatter schema + heading skeleton.

```text
# fences do not break the section model
```

## Drawbacks

Frontmatter is a YAML subset — exotic shapes stay unsupported.

## Alternatives

Free-form docs plus lint rules.
