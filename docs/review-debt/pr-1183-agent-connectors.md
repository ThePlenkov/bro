# PR #1183 connector review debt

This record closes the deferred review findings from the connector extraction
in [PR #1183](https://github.com/ThePlenkov/bro/pull/1183). Each finding was
compared with the merge-base `agent-connectors/core.ts` monolith before being
classified. “Moved pre-existing” means the extraction changed the file
location, not the behavior; it is still recorded here rather than silently
treated as fixed.

## Findings

| Finding                                        | Triage                                                          | Evidence and action                                                                                                                                                                                                                                                                                                                                                                                                 |
| ---------------------------------------------- | --------------------------------------------------------------- | ------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `tmux.ts:279` Kody shell injection             | False positive / unsafe recommendation                          | `shQuote` is the shell-quoting boundary used by the monolith (`core.ts` around lines 4921–4924 at the merge-base). Removing it, as the bot suggested, would make injection more likely. `runLine` is produced by the existing worker command builder and every interpolated file path is quoted. No change.                                                                                                         |
| `tmux.ts:84` Kody synchronous `tmuxRun`        | Moved pre-existing; deferred                                    | `tmuxRun` was synchronous in the monolith and is also used under the registry lock. Making only the initial version probe async would not remove the blocking probes in `prepareSpawn`, `tmuxProbe`, or status/stop paths. No semantic change was made in this debt pass.                                                                                                                                           |
| `docker-basic-harness.ts` performance findings | Moved pre-existing; deferred                                    | The helper is a direct extraction of the monolith's Docker subprocess and parsing helpers. The synchronous Docker CLI contract is shared with git/gh/bd and is intentionally preserved. No change.                                                                                                                                                                                                                  |
| `docker-jsonc.ts:81` whitespace rescan         | **Fixed**                                                       | The lookahead now runs only for commas. Non-comma whitespace is copied once, avoiding the quadratic rescan reported by Macroscope.                                                                                                                                                                                                                                                                                  |
| Gas City session snapshot semantics            | Already fixed before this pass                                  | `gcEntryIsLive` now treats the pre-lock snapshot as proof of life only and refreshes non-active/missing rows under the lock. Recovery closes the actual `city`, not the molecule step. These are present in `gascity.ts` lines 113–136 and 143–158.                                                                                                                                                                 |
| Aikido file inclusion findings (five reads)    | Moved pre-existing; no exploitable caller-controlled path found | The reads are constrained to operator/runtime paths: the agent home and attempt filenames are derived from minted registry IDs; Gas City reads the git-common-dir city descriptor and fixed template filenames; Docker reads the validated devcontainer descriptor and Dockerfile under the configured repository. These paths and reads existed in the monolith. No broad waiver or weakened validation was added. |
| CodeScene connector findings                   | Moved pre-existing; deferred                                    | The complexity, primitive/string-argument, and file-size findings reported on extracted connector modules compare equal to the merge-base monolith's implementation. The deleted `spawn-harness.ts` findings are obsolete, not new debt. No suppressions were added.                                                                                                                                                |

The one code change is covered by the existing JSONC behavior tests in
`packages/cli/src/agent-connectors.test.ts`; comments and trailing commas
continue to be handled, while the hot path no longer rescans whitespace.
